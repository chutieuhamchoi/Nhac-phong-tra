Sao lưu đầy đủ

Một file gồm toàn bộ kho bài (mọi phiên bản, điểm, lịch sử) và tiến độ lịch 15 tuần. Nên tải về mỗi tuần.

Khôi phục từ bản sao lưu

Thay toàn bộ dữ liệu trong trình duyệt bằng file đã chọn. Trước khi thay, trang tự lưu một bản hiện tại.

Đồng bộ với GitHub

Trang không tự ghi lên GitHub. Muốn lưu kho lên repo: tải file dưới đây rồi thay data/kho-bai.json trong repo (hoặc gửi cho Claude).

Gộp: chỉ thêm bài chưa có, bài trùng mã được bỏ qua, không ghi đè. Nhận cả file kho cũ.
